Domain Name System (DNS)

DNS translates human-friendly domain names into numerical IP addresses so computers can locate each other on the Internet. DNS works by translating human-friendly names like google.com into machine-friendly IP addresses. When you enter a domain, your computer asks a DNS server to find the matching IP. This process happens in milliseconds, making it possible to browse the web without memorizing long strings of numbers.
